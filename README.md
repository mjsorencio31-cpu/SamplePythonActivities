# Google Colab Activity
## Description
This program is used to run the distance formula for 2 coordinates
## How it works
First, you import a math library into the program, Then make 4 variables set to input so you get to make the coordinates. After, you recreate the formula using "math.sqrt" and "math.pow". To use the "math.pow", you first have to put the equation for each coordinate, then put "math.pow" then the formula for each coordinate
